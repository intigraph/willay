# Willay

Agents write the episode; Willay performs it. An agent-authored TOML script
becomes multi-host ElevenLabs dialogue, local or generated effects, transitions,
a ducked music bed, a measured MP3, chapters and show notes. An optional private
RSS feed gives a listener one subscription.

Willay does not call a language model. Python 3.12+, uv and ffmpeg are its runtime;
the pinned dependency supplies ffmpeg when the host has no system binary.
Source, provider generation, host installation and phone playback are separately
verified stages. Offline tones prove the audio pipeline, not generated speech.
